How to Run
create new virtual env.:
  python -m venv venv
  ps:>  .\venv\Scripts\Activate
Install dependencies:
  # install logger project
  .\venv\Scripts\activate
  pip install -e ../logger_project
  # install additional libs
  pip install selenium selenium-stealth
  pip install requests beautifulsoup4
Configuration:
Setup relevant search_url and filters in main.py
Run it:
console:
    python main.py
    python main.py -choice=Linkedin_job -url="...start page with list of jobs..."
gui:
    python jobscrapergui.py

Log into LinkedIn manually when the browser opens (solve CAPTCHA if shown).
The script will scrape jobs and save them in linkedin_job.txt for linkedin choice.
